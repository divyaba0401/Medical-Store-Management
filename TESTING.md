# Testing Documentation

## Medical Store Management System

### 1. Introduction

The Medical Store Management System was tested to check the working of its main modules and available operations.

### 2. Test Cases

| Test Case | Operation Tested | Expected Result |
|---|---|---|
| TC01 | Launch the program | Main menu is displayed |
| TC02 | Open Medicines | Medicine menu is displayed |
| TC03 | Add a medicine | Medicine record is added |
| TC04 | View medicines | Available medicine records are displayed |
| TC05 | Open Suppliers | Supplier menu is displayed |
| TC06 | Add a supplier | Supplier record is added |
| TC07 | Search supplier | Matching supplier record is displayed |
| TC08 | Open Sales | Sales menu is displayed |
| TC09 | Record a sale | Sale record is added |
| TC10 | Open Categories | Category menu is displayed |
| TC11 | Open Supplier Orders | Supplier order menu is displayed |
| TC12 | Exit the program | Program terminates |

### 3. Testing Method

The application can be tested by selecting menu options, entering sample data, viewing stored records, and checking the displayed messages.

### 4. Limitations

The current version stores records temporarily in memory. The records are not permanently saved after the program closes.

### 5. Conclusion

Testing helps verify that the main menus and implemented operations behave as expected. Test cases should be marked successful only after the corresponding operations have been performed and checked.
