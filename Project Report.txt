# ABSTRACT

The Medical Store Management System is a Python-based menu-driven application developed to organize common operations of a medical store. The system provides separate modules for medicines, suppliers, sales, categories, and supplier orders.

Users can add and view medicine records, manage supplier information, record sales, maintain medicine categories, and create and search supplier orders. The system uses Python lists and dictionaries for storing information during program execution.

The project demonstrates how fundamental programming concepts can be combined to create a practical application with multiple related modules and a simple command-line interface.

---

# 1. INTRODUCTION

A medical store handles several types of information on a regular basis, including medicine details, supplier information, sales records, categories, and supplier orders. Managing such information manually can make it difficult to organize and retrieve records efficiently.

The Medical Store Management System provides a simple computerized approach to these operations. It uses a menu-driven interface through which the user can select a required module and perform the available operations.

The project focuses on applying basic Python programming concepts to a practical application while maintaining a simple and understandable interface.

## 1.1 Problem Statement

The project aims to develop a Python-based application that can organize basic medical store records and provide operations for adding, viewing, searching, updating, and deleting selected records.

The program uses separate lists for:

* Medicines
* Suppliers
* Sales
* Categories
* Supplier Orders

Each individual record is represented using a Python dictionary containing the required fields.

For example:

Medicines → List of medicine dictionaries

Suppliers → List of supplier dictionaries

Sales → List of sales dictionaries

Categories → List of category dictionaries

Orders → List of supplier order dictionaries

# 10. IMPLEMENTATION

The project is implemented as a command-line Python application. A continuous loop maintains the main menu until the user chooses the Exit option.

Each major module has its own menu and operations.

Lists are used to store multiple records, while dictionaries store the fields belonging to an individual record.

For example, a medicine record contains fields such as Medicine ID, Medicine Name, Manufacturer, Category, Price, Quantity, and Expiry Date.

Search operations use loops to examine records and conditional statements to compare the entered value with stored values.

Update operations modify dictionary values, while delete operations remove the matching record from the corresponding list.
